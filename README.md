# What to cook

## Recipe System 2.0 — импорт каталога

Каталог работает только из Supabase и не зависит от внешнего API во время обычной работы. Административный импорт получает оригинальные данные из [TheMealDB](https://www.themealdb.com/), сохраняет идентификатор и ссылку источника и повторно запускается без дублей.

1. Примените новые миграции обычным `supabase db push` (без reset).
2. Задайте локально `NEXT_PUBLIC_SUPABASE_URL` и `SUPABASE_SERVICE_ROLE_KEY`. Service role предназначен только для этого административного скрипта и не должен попадать в Git или клиентский `.env`.
3. Для проверки тремя реальными рецептами: `npm run recipes:seed`.
4. Для импорта всей доступной публичной базы по алфавиту: `npm run recipes:import`.

Импорт детерминированно нормализует названия и основные ингредиенты в fingerprint группы, сохраняет варианты в одной canonical group и делает upsert по паре `source_name + external_id`.
